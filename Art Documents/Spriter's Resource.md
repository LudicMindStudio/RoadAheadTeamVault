# Tools
---

Spriting can be done with virtually any graphics editing program. The specifications aren't really high. Mainly you just need a paintbrush that can dry one pixel at a time. It's best to use whichever you are most comfortable with, but I will list some well-known programs.

| Name         | Platform      | Price                |
| ------------ | ------------- | -------------------- |
| Graphicsgale | Windows       | Free                 |
| Aseprite     | Win/Mac/Linux | 14$ (On steam)       |
| piskel       | Browser       | Free                 |
| Pixen        | Mac           | Free                 |
| Krita        | Win/Mac/Linux | Free (Paid on steam) |
| PikoPixel    | Mac/Linux     | Free                 |


If you don't know which to pick, I would recommend Aseprite as it is the most feature filled. If you don't want to spend money then I would recommend Graphicsgale.

As mentioned above, you can do pixel art with pretty much any image editor so use which is most comfortable for you.

# Palettes
---

Originally, spriting was used in older gaming consoles. Due to hardware limitations, the number of unique colors that a sprite could have was quite low. For example, on the gameboy advance sprites only had 16 colors to work with and usually one of those colors has to be used as a transparent channel. As such, this sort of minimalism informs many of the design choices for spriting.

![[PaletteExample.png]]

Here you can see there are only 3 colors for the hair, 3 colors for the clothes, 5 colors for the skin, and the remaining five colors make up smaller details, the outline and the transparent background.

While we don't have to deal with these constraints, we should still keep the spirit of minimalism in mind. A good approach is to use about 3-5 shades for each color. Though personally, I find that 5 is usually excessive except for skin colors.

Speaking of skin colors, we should create some presets for different skin tones and share them amongst each other. This helps to keep some consistency between sprites.

# Small and Large Sprites
---

Depending on the scale of the sprite, there are different approaches.

--Small Sprites

Smaller portraits usually refer to tilesets, map character sprites, ui elements.

When drawing smaller sprites it's a good idea to think of them like caricatures. Try to single out the most defining characteristics and focus on those. It also helps to use a palette with more contrast to help it pop. Though you might not always want to draw attention to a sprite. For example, you might prefer it if the tileset doesn't stand out so much so that it doesn't draw attention away from the character map sprites.

# Anti-Aliasing
---

Naturally, pixel art tends to be jagged looking on it's own. Anti-aliasing is a technique that softens those jagged edges. This involves making color gradients between different colors along the edges of places where two colors meet.

That sounds a bit complicated so here is a visual aid.
