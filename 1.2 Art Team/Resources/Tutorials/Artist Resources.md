# Artist Kanban How To
**Usage**
Artist Kanban is used to distribute tasks for the artist team & to track progress. Each card will contain info like:
* Type of task
* Deadline
* Tag (precising task difficulty) 
* *optional* Link to a page (ex. link description of a character)

Legend:
* *#Fast* = Type of task is faster than others
* *#Medium* = Type of task takes a bit more time
* *#Challening* = Type of task takes a while to complete
* *#ASAP* = Deadline is very soon

**Artist usage of Kanban
* Add your name to the task (for each card) by clicking the 3 dots & select *Edit*
* Drag the card to *In Progress* right after putting the name to the task
* If you have any questions, or you feel like you might not finish the task, let the leader know. No pressure we all understand! The leader might also check in if the task is in *In Progress*  
* Once completed, add the drawing to *Google Drive* -> *Game Assets* https://drive.google.com/drive/folders/1c0iWhtdTRLw5NbaBv3geTCRxEtOcN0Y-?usp=drive_link 
* Drag the card to *Complete* once the task is complete 

**Team Leader usage of Kanban**
* Add new tasks (cards)
* Check in with artists, give feedback/answer questions 
* Make sure the art is unified
