## Why

The player interacts with the game through UI surfaces. The wheel menu is the primary navigation — each segment needs an icon. The submenus (Notebook, System, Inventory) each have their own visual theme.

## Context


**Wheel icons:** 
a wheel shows up around lakshmi when the player access the main game ui. each wheel section has a different icon

**Notebook theme:** 
notbook holds a lot of info rich ui: Journal, Map, Dialogue History, Relationship pages, etc. Sticky notes or bookmarks as tab between sections of the notebook. the main ui elements fall ono lined paper.

**System UI theme:** A bulletin board. Different notices pinned to it for each option and setting. Each notice is a different paper colour, pinned with a tack.

**Inventory / Backpack theme:** A backpack or bag container with a grid cell layout for items. The bag itself is the frame. Items sit in grid slots.
