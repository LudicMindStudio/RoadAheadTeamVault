## Why

When the same tile type repeats across a large area, it looks uniform and flat. General variants are drop-in replacements — same style, same size, same function, but a different visual so the world feels organic. The rule tile engine can pick randomly between them.

## Context

These are not height-matching variants. These are simple cosmetic alternates. A grass tile gets 3 different looks, all 16x16, all grass, but one has a small flower, one has a darker patch, one is plain. The engine picks randomly when placing tiles. Same for path tiles, wall tiles, dirt tiles.

## What to Make

- [ ] Grass tile — 3 variants (plain, with small flower, with darker patch)
- [ ] Dirt tile — 3 variants (plain, with pebbles, with worn patch)
- [ ] Path cobble tile — 3 variants (tight cobble, spaced cobble, worn cobble)
- [ ] Wall tile — 3 variants (plain, cracked, with moss)
- [ ] Water tile — 2 variants (calm, ripple)
- [ ] Wood floor tile — 3 variants (clean, scuffed, with grain variation)
