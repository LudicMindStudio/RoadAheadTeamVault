# Interactable Description

## Root Location

[[Dolphin Bay Sanctuary - Location Outline]]

## Object Description

A rope-and-pulley system connects to a line of buoys floating in the bay outside the dolphin pens. The rope is worn but functional. Pulling it raises or lowers the buoy line with a faint mechanical creak across the water.

## Object Logic

No quest logic. Lakshmi can interact at any time.
