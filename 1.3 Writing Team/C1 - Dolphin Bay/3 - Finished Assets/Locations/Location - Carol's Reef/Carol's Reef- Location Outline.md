# Location Description

## Purpose

Juliette's motel/inn. No one really remembers who Carol was, but the name stuck, and Juliette is the latest in a long line of managers for the motel. 

## Vibe and visual description

Cute and tacky smalltown motel with an especially large front office. Juliette has fully adopted the retro aesthetic and kept the bright colours and patterns you might associate with the 70s. It's shaped very much like the image above with the six cabins and the haystack forming a semi-circle. 

It's most iconic feature is the motel sign standing proudly like in the image above, only the sign is shaped like a big pink coral reef and a silly looking clown fish
